This project provides a REST API for managing users, roles, and permissions in the 
Identity Link system. It is designed to securely handle user credentials, 
enforce role-based access control, and support standard authentication and 
authorization workflows.

## API Documentation

- [Swagger Editor](https://editor.swagger.io/)
